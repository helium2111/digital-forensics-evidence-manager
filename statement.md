# Project Statement

## Problem Statement

Digital investigations may involve multiple evidence items, investigators, transfers, and analysis records. Without structured tracking, it can be difficult to maintain an organized record of evidence ownership and integrity. The Digital Forensics Evidence Manager provides a small Java-based system for organizing fictional investigation cases and their associated digital evidence.

## Scope

The project focuses on:
- Managing investigation cases
- Registering digital evidence
- Recording chain-of-custody events
- Calculating and verifying SHA-256 hashes
- Producing a basic investigation summary

The project is educational and does not perform real-world device intrusion, password recovery, deleted-file recovery, or unauthorized data extraction.

## Target Users

- Investigators managing case records
- Forensic analysts reviewing evidence
- Students learning Java programming and software design

## High-Level Features

1. Case Management
2. Evidence Management
3. Chain of Custody
4. SHA-256 Evidence Integrity Verification
5. Investigation Summary Report
